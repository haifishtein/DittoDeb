# DittoDeb — Clon de Ditto para Linux Mint (.deb)

Clon de [Ditto](https://github.com/sabrogden/Ditto) (GPL-3.0) para Linux Mint,
empaquetado como `.deb`. Basado en DittoX (Tauri 2 + Rust + TypeScript + SQLite FTS5).
Local-first, sin cloud/telemetria.
